# 💳 Credit Card Fraud Detection

A machine learning project for detecting fraudulent credit card transactions using **XGBoost** and **SMOTE** to handle severe class imbalance.

## 📌 Objective

The objective of this project is to identify fraudulent credit card transactions from a highly imbalanced dataset.

The target variable is:

- `0` → Non-fraudulent transaction
- `1` → Fraudulent transaction



### Features

The dataset contains:

- `Time`
- `V1` to `V28`
- `Amount`
- `Class` — Target variable

The `V1`–`V28` variables represent anonymized transaction features.
